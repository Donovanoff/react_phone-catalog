> A fully functional, responsive e-commerce web application for gadgets (Phones, Tablets, and Accessories).

## 🔗 Live Demo
[View the Live Project Here](https://donovanoff.github.io/react_phone-catalog/)

## 📖 About the Project

This project is a modern, single-page e-commerce application built to demonstrate advanced frontend development skills. It faithfully recreates a professional online store experience based on detailed Figma designs. 

The application handles complex state management, dynamic routing, data fetching, and local storage persistence to provide a seamless shopping experience for users browsing mobile devices and accessories.

## 🛠️ Technology Stack

- **Core**: React, TypeScript
- **Styling**: SCSS (CSS Modules)
- **Routing**: React Router 
- **Build Tool**: Vite
- **Testing & Formatting**: Cypress, ESLint, Prettier, Stylelint

## ✨ Key Features

- **Product Browsing & Filtering**: 
  - Dedicated pages for Phones, Tablets, and Accessories.
  - Advanced sorting (by Age, Alphabetically, Price).
  - Pagination to handle large datasets efficiently.
- **Dynamic Search**: Real-time search functionality with debouncing to prevent excessive rendering.
- **Shopping Cart & Favorites**: 
  - Add/remove items to the cart and manage quantities.
  - "Like" products to save them to a Favorites list.
  - Global state persistence using `localStorage` so users don't lose their data upon refreshing.
- **Detailed Product Pages**: 
  - In-depth specifications.
  - Ability to switch between different colors and storage capacities.
  - "You may also like" dynamically suggested products slider.
- **Responsive & Interactive UI**: 
  - Interactive carousels (`PicturesSlider`, `ProductsSlider` for Hot Prices and Brand New items).
  - Smooth transitions, hover effects, and skeleton loaders for a premium feel.
  - Fully responsive design ensuring flawless display on mobile, tablet, and desktop devices.
